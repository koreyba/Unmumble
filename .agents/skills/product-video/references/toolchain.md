## Kokoro

Окружение: `<проект>/.kokoro/bin/python`, утилита `<проект>/kokoro-speak.py`.

Пример пробы:

```sh
/Users/denys.koreiba/Documents/Unmumble-Reel-2026-09-29/.kokoro/bin/python \
  /Users/denys.koreiba/Documents/Unmumble-Reel-2026-09-29/kokoro-speak.py \
  'Missed it? Go back one phrase.' \
  --voice af_bella --speed 1.12 --output /absolute/new-video/voice-sample.wav
```

Замени выходной путь на реальную папку ролика. Утилита сохраняет WAV и JSON с параметрами; словесные тайминги создаёт отдельный сценарий `prepare-remotion-voices.py`. Передавай текст безопасными аргументами процесса, не подставляй реплики в исполняемый shell-код.

Bella — выбор текущего пресета, не обязательный голос. Для другого языка проверь поддержку голоса и язык KPipeline. Скорость задавай при генерации, затем измеряй длительность. При выборе нового голоса короткая проба полезнее генерации всей озвучки сразу.

### Русский язык и альтернативные движки

В установленном Kokoro `LANG_CODES` не содержит русского языка; `lang_code='ru'` не является рабочим маршрутом. Не пытайся озвучивать русский текст Bella или менять язык ролика на английский ради движка. При выключенной озвучке языковой маршрут TTS вообще не нужен.

Для русского на этом Mac в `say -v '?'` доступна `Milena` (`ru_RU`). Это техническая альтернатива, а не проверенное качество рекламного голоса. Если выбор движка свободен, создай короткую пробу; если пользователь требует конкретный голос или качество непригодно, используй уже подключённый поддерживающий русский TTS либо сообщи, какой инструмент нужен. Не подключай платный сервис автоматически.

Пример macOS-пробы, когда она требуется задачей: сохрани реплику в UTF-8 `narration-ru.txt` в новой папке, затем выполни из неё:

```sh
say -v Milena -f narration-ru.txt -o voice-sample.aiff
ffmpeg -i voice-sample.aiff -ar 48000 -c:a pcm_s16le voice-sample.wav
```

Перед запуском проверь, что выходные файлы не заменяют утверждённые исходники. Скорость `say -r` измеряется словами в минуту, не множителем Kokoro; задавай `narration.rate_wpm`, если нужен этот параметр. Измерь длительность и прослушай файл. `say` не выдаёт словесные тайминги: используй фразовые титры по фактической длительности либо доступное выравнивание, если нужны подсвечиваемые слова. Не выдавай равномерно распределённые тайминги за точное выравнивание.

### Перенос титров и ролик без голоса

В историческом `remotion/src/Title.tsx` сопоставление слов использует фильтры `[^A-Z]`/`[^a-z]`: кириллица удаляется. В новой копии проекта адаптируй обе стороны сопоставления к Unicode, например нормализация NFC + `toLocaleLowerCase(locale)` + удаление символов вне `\p{L}`/`\p{N}` с флагом `u`; проверь слова с пунктуацией и фактическое совпадение токенов. Для фразовых титров можно обойтись без сопоставления слов. Проверь шрифт, переносы и длительность на русском фрагменте до полного рендера.

Существующий Title также безусловно обращается к записи narration и вставляет Audio. Для ролика без голоса в новой композиции убери/сделай условными эти зависимости и рассчитывай появление титров по сценовым меткам. JSON-бриф сам не отключает элементы старого шаблона. Адаптация требуется в копии для нового ролика; исправление этого скилла не изменяет одобренный проект.

### Проверенный короткий маршрут YuE2 без symbolic planner

Если планировщик инструментального режима выдаёт непригодный ABC либо для короткой пробы выбран прямой аудиомаршрут, используй нативный `yue2 generate --cot off`. Аудио по-прежнему создаёт модель; агент не пишет ноты. Не выдавай этот режим за проверку/сохранение партитуры и не используй его вместо явно запрошенного score/cover workflow.

На этом Mac команда `/Users/denys.koreiba/.local/bin/yue2 generate --help` поддерживает request/config/output, cot off и MPS. Перед запуском прочитай LOCAL_SETUP.md, проверь CLI и доступные веса. В успешной короткой пробе использовался `YUE2_NAR_ENGINE=torch`: PyTorch BF16 AR/NAR, 32 NAR steps, FP32 VAE decoding; не приписывай эти параметры другому runtime без проверки логов.

Создай в **новой** папке `request.json` с `id`, `style` из брифа, `lyrics: ""`, `cot: "off"` и seed. Для двух вариантов используй разные seed/акценты описания. Пример параметров `preview-config.json`: `{"semantic": {"min_tokens": 500, "max_tokens": 625}}`. В проверенной модели 25 codec frames/s это давало примерно 25 секунд; ограничение max_tokens может обрезать конец, поэтому результат — прослушиваемая проба, не готовая законченная композиция.

```sh
YUE2_NAR_ENGINE=torch /Users/denys.koreiba/.local/bin/yue2 generate \
  --request request.json --cot off --config preview-config.json \
  --device mps --backend torch --quantization none --output output-01
```

Пути выше разрешаются относительно новой папки. Запиши фактические логи, выходные файлы и длительность. Вторую генерацию запускай после завершения первой. Для пригодности нужны проверка файла и отдельная проба для пользователя; пустые lyrics/запрет вокала в prompt не гарантируют отсутствие слов. Если прямая генерация тоже не работает, сообщи причину и продолжай независимые этапы видео. Общий подбор **2 локальные + 2 Pixabay** и ожидание выбора описаны в [music-selection.md](music-selection.md).
