# Музыка: четыре отдельные пробы до монтажа

Читать, когда для ролика нужна новая музыка. Переиспользование прямо выбранного трека и отключённая музыка не требуют нового подбора. Текущие указания пользователя имеют приоритет.

## Подготовить набор

1. Из брифа составь общее описание: настроение, энергия, темп, инструменты, вокал/инструментал, длительность и место для речи. Не закрепляй барабаны или жанр за всеми роликами. Для озвученного видео при отсутствии другого указания выбирай инструментал без слов.
2. Сгенерируй **две новые дорожки установленной локальной моделью**. Варианты должны отличаться, но отвечать одному брифу. Сохрани реальные промпты, seed, режим, параметры, модель и файлы. На одном локальном ускорителе запускай тяжёлые генерации последовательно; видео можно готовить независимо. Рабочий короткий маршрут YuE2 описан в [toolchain.md](toolchain.md).
3. Найди **две разные дорожки на [Pixabay Music](https://pixabay.com/music/)** по тому же описанию. Переведи его в короткие поисковые запросы по жанру, инструментам и темпу. Проверь характерный фрагмент, отсутствие нежелательного вокала и пригодность для речи. Сохрани название, автора, страницу дорожки, выбранный отрезок, условия использования и доступный сертификат лицензии; проверь отметку Content ID перед доставкой на платформы.
4. Подготовь четыре доступных для прослушивания образца, обычно по 15–30 секунд из характерного места. Приведи их к сопоставимой громкости, сохрани оригиналы. Для короткой локальной генерации честно укажи, что это проба, и после выбора подготовь достаточную длину без слышимого шва. Не принимай метаданные «instrumental» или пустые lyrics за доказательство отсутствия голоса.

## Доступ к Pixabay

Сначала проверь доступные MCP/CLI. Используй только реально поддерживаемый музыкальный поиск/скачивание. В [публичной документации Pixabay API](https://pixabay.com/api/docs/), проверенной 30 сентября 2026 года, описаны изображения и видео; публичный endpoint музыкального поиска там не документирован. Не придумывай `/api/music/` и не выдавай поиск видео категории music за аудиотреки. При отсутствии подходящего API ищи через Music-раздел сайта доступным браузерным инструментом. Не обходи ограничения доступа; при недоступности источника сообщи, какие два варианта пока не получены.

Для внешних медиа предпочитай доступный нативный проигрыватель/preview. Если файл штатно получен для монтажа, показывай отдельный локальный аудиофайл. Не скачивай медиа лишь для обхода ограничений отображения. Если воспроизведение невозможно, дай прямую страницу трека и обозначь ограничение; не утверждай, что пользователь уже получил прослушиваемый сэмпл.

## Выбор до добавления в видео

Отправь четыре пробы отдельными аудиоэлементами: «1 — локальная», «2 — локальная», «3 — Pixabay: название», «4 — Pixabay: название». Для каждой добавь одну короткую характеристику. Локальное аудио в Codex показывай как `![Вариант 1](/absolute/path/sample-01.wav)`; для Pixabay используй доступный preview или ссылку на проверенную страницу.

Попроси выбрать номер, заменить варианты или оставить ролик без музыки. **До ответа не добавляй ни одну дорожку в видео**, включая черновой ролик: предварительное предпочтение агента не является выбором пользователя. Можно продолжать сценарий, захват, озвучку, анимацию и экспорт версии без музыки. Это независимые этапы, а не требование ждать готовности всех дорожек перед работой над картинкой.

Если источник или модель недоступны, предложи готовые отдельные пробы и точно назови недостающие. Не заменяй состав 2+2 без прямого указания и не представляй две дорожки как завершённый набор. После адресной попытки устранить причину останови зависимый этап, сохраняя прогресс видео.

Сохрани `music/candidates.json`: четыре записи с id, origin (`local_model`/`pixabay`), файлом или проверенным preview/page URL, длительностью пробы, описанием, происхождением и условиями использования. Выбор запиши в бриф и manifest: id, основание из ответа пользователя, исходный файл и выбранный отрезок. Только затем сделай микс: плавное приглушение под авторской и продуктовой речью, более громкая музыка в паузах. Проверяй готовый микс отдельно от сэмпла.
