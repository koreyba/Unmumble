# Настройки брифа

Бриф и пресет читаются агентом, это не программный API Remotion. Поля ниже описывают решения; новые параметры можно добавить под конкретную задачу.

## Наследование

- Явное указание пользователя важнее сохранённых настроек.
- Заполненные поля брифа переопределяют пресет по соответствующим вложенным ключам. `style_overrides` переопределяет только стилистические поля `style`, а не голос или захват. Для этих слоёв используй явные секции брифа.
- `null`, пустая строка и отсутствующий ключ означают «не задано, взять из подходящего пресета или выбрать по задаче». `false` не считать пустым значением.
- `enabled: false` явно выключает весь слой независимо от оставшихся в пресете voice/source/device. Для удаления унаследованной рекламы выключи CTA целиком либо задай `cta.offer_enabled: false`, сохраняя собственный призыв. `offer: null` сам по себе старое предложение не удаляет.
- Перед производством сохрани разрешённые настройки без неопределённых `enabled`. Если пресета нет, выбери слои по задаче: голос/музыка не обязательны; захват нужен для новой съёмки; звук захвата — лишь для используемого звука продукта. Уже имеющиеся медиа не требуют новой съёмки.
- При изменении языка заново выбери совместимые движок, голос и титры; не наследуй несовместимый голос. `language` задаёт язык авторского текста, а речь из продукта может быть на другом языке.
- `format` описывает экспорт; `capture.viewport` — CSS-размер интерфейса. Они не связаны автоматически. `capture.layout` — `desktop`/`mobile`; `device` применим к mobile. При повторном использовании медиа `capture.enabled: false`, а включение их звука по-прежнему определяется `capture.audio.enabled`.
- `titles.timing`: `phrase`, `word` или `scene`. Без голоса используй сценовые интервалы и время чтения; без словесного выравнивания не обещай точную пословную синхронизацию.

## Выбор музыки и компоновка

Для новой музыки `music.selection_policy: "two_local_two_pixabay"` задаёт две новые локальные генерации и две найденные дорожки Pixabay. `music.description` содержит настроение, темп, инструменты и требования к вокалу; число вариантов не зависит от жанра. `approval_required_before_mix: true` означает отдельное прослушивание и выбор, а не согласование всего монтажа. `selected_track` заполняй только после выбора пользователя, `selection_status` — `not_started`, `in_progress`, `awaiting_choice` или `selected`. При недоступном источнике статус остаётся `in_progress`; укажи недостающие варианты. Подробности в [music-selection.md](music-selection.md).

Явно выбранная или предоставленная дорожка может сразу получить `selection_status: "selected"` с записью основания из разговора. `music.enabled: false` отключает подбор и смешивание. Новое прямое указание пользователя меняет эти настройки без редактирования скилла.

`style.scene_pattern` и `style.demo_layout` управляют стилем: пресет Unmumble объединяет инструкции и демонстрацию, сохраняя отдельные зацепку и финал. Это стилистический выбор; JSON не перестраивает существующую композицию автоматически.

## Desktop SaaS, 20 секунд, музыка без голоса

Это фрагмент для заполнения брифа, не самостоятельный проект. Файл музыки и продукт берутся из поручения:

```json
{
  "target_duration_seconds": 20,
  "style_preset": null,
  "format": {"width": 1080, "height": 1920, "fps": 30},
  "narration": {"enabled": false},
  "music": {"enabled": true, "source": "provided_audio"},
  "titles": {"enabled": true, "timing": "scene"},
  "capture": {
    "enabled": true,
    "layout": "desktop",
    "viewport": {"width": 1440, "height": 900},
    "audio": {"enabled": false}
  },
  "cta": {"enabled": false},
  "delivery": "local_video"
}
```

Голосовые скиллы/тайминги и разрешения на звук вкладки здесь не нужны. Музыка сохраняет ровную громкость без приглушения под отсутствующую речь. Для полностью немого ролика дополнительно задай `music.enabled: false`.

## Русское обучение по имеющимся мобильным исходникам

Для нового учебного ролика выбери спокойный стиль без рекламного пресета; не наследуй Bella и For Free. Возможный фрагмент:

```json
{
  "language": "ru",
  "style_preset": null,
  "style_overrides": {"mood": "calm, clear, encouraging"},
  "narration": {"enabled": true, "engine": "macos_say", "voice": "Milena"},
  "titles": {"enabled": true, "timing": "phrase"},
  "capture": {"enabled": false, "layout": "mobile", "audio": {"enabled": true}},
  "cta": {"enabled": true, "text": "Попробуйте на одной фразе", "offer_enabled": false},
  "delivery": "local_video"
}
```

Milena — кандидат для пробы, не утверждённый художественный результат. Проверь пригодность имеющихся исходников: если для нужного действия нет доказательной записи, запланируй новую съёмку или сузь демонстрацию в соответствии с поручением. Выбор русской TTS и адаптация титров описаны в [toolchain.md](toolchain.md); изменения самого видеошаблона здесь не выполнялись.
